# دهم ریاضی سعدی

محیط تمرین ایستای فصل اول ریاضی دهم، بازیابی‌شده از پشتیبان Google Drive و تکمیل‌شده برای انتشار در GitHub Pages.

**یاد بگیر، تمرین کن، پیشرفت کن.**<br>
**طراحی و توسعه: آرمان · Made by Arman Es**

## اجرا

پروژه با HTML، CSS و JavaScript ساده ساخته شده و مرحلهٔ build یا backend ندارد. از ریشهٔ پروژه یک سرور فایل ایستا اجرا کنید، برای نمونه:

```sh
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای تجربهٔ محلی کامل، اتصال اینترنت جهت فونت Vazirmatn و KaTeX از CDN لازم است؛ در صورت قطع CDN، متن و تمرین‌ها همچنان قابل استفاده‌اند و عبارات ریاضی به‌صورت LTR ایزوله نمایش داده می‌شوند.

## محتوای آموزشی

- درس ۱: مجموعه‌های متناهی و نامتناهی
- درس ۲: متمم یک مجموعه
- درس ۳: الگو و دنباله
- درس ۴: دنباله‌های حسابی و هندسی
- هر درس دو بانک مستقل «مفاهیم و تعاریف» و «مسائل و محاسبات» با دشواری آسان، متوسط و سخت دارد.
- پاسخ‌های نخستین تلاش، دقت، پیشرفت و XP تمرین برای هر بانک جدا ثبت می‌شوند.
- آزمون فصل، آزمون هر درس، چالش روزانه، دستاوردها و آمار نیز موجود است.

## مهمان و حریم خصوصی

هیچ ثبت‌نام، ایمیل یا شمارهٔ تلفنی لازم نیست. دانش‌آموز نام نمایشی را خودش وارد می‌کند. پاسخ‌ها و پیشرفت در `localStorage` مرورگر ذخیره می‌شوند و به سرور ارسال نمی‌شوند؛ پاک‌کردن داده‌های مرورگر یا استفاده از دستگاه دیگر این اطلاعات را منتقل نمی‌کند. شناسهٔ ذخیره‌سازی `saadi-v1` و شناسه‌های پرسش‌های نسخهٔ پشتیبان برای حفظ سازگاری نگه داشته شده‌اند.

## انتشار

GitHub Actions در هر push به شاخهٔ `main` سایت استاتیک ریشهٔ مخزن را به GitHub Pages منتشر می‌کند. به build جداگانه یا base path نیاز نیست؛ از مسیرهای نسبی برای CSS و JavaScript استفاده شده است. فایل `.nojekyll` نیز در ریشه قرار دارد.
